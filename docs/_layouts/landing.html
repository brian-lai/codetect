codetect

Fast, token-efficient codebase search for every LLM.

A local MCP server that brings Cursor-like performance to Claude Code and any LLM tool through intelligent codebase indexing.

85.7% Accuracy
0% Token Overhead
4 MCP Tools
Get Started View on GitHub

4 Tools. Complete Codebase Access.

search_keyword

Fast regex search powered by ripgrep with configurable detail levels — minimal, standard, or rich context.

get_file

Read any file with optional line-range slicing. Retrieves exactly the code you need without wasting tokens.

symbols

Symbol lookup and file definition listing. Find functions, classes, and types instantly with mode=find or mode=list.

hybrid_search_v2

Combined keyword + semantic search with cross-encoder reranking. Ask natural language questions about your codebase.

Get Running in 3 Steps

1

Install

git clone https://github.com/brian-lai/codetect.git
cd codetect
./install.sh
2

Index your project

cd /path/to/your/project
codetect init      # Creates .mcp.json
codetect index     # Index symbols + embeddings
3

Search

# Start Claude Code — codetect tools are
# automatically available via MCP
