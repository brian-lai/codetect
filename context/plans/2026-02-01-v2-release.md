# codetect v2.0.0 Release Plan

**Date:** 2026-02-01
**Author:** Claude Sonnet 4.5
**Status:** Ready for Review

## Objective

Release codetect v2.0.0 with comprehensive documentation and migration tooling for users upgrading from v1.13.0.

## Context

- **Current state:** v2 features merged to main (commits d6b84a0, 0002e91) but not tagged
- **Latest release:** v1.13.0 (commit 2bd4d40)
- **Major changes:** Cursor-inspired RAG architecture, 15x faster indexing, 4x faster search
- **User decisions:**
  - Release ASAP (today/tomorrow)
  - install.sh only (no pre-compiled binaries)
  - Maintain v1.x branch for critical fixes
  - Announce via GitHub Release + blog post

## Rollback Plan

If critical issues found after release:

1. **Hot fix on main:**
   - Fix bug on main branch
   - Tag v2.0.1 with fix
   - Create new GitHub release

2. **Revert release (extreme):**
   - Delete v2.0.0 tag: `git push origin :refs/tags/v2.0.0`
   - Mark GitHub release as draft
   - Fix issues, re-release

3. **Point users to v1.x:**
   - Users can: `git checkout v1.13.0 && make build && make install`
   - v1.x branch available for critical fixes
