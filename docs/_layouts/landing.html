How it works

⚡ ripgrep Instant keyword & regex search across your entire codebase
+
🧠 Embeddings Semantic search via Ollama or LiteLLM — runs locally, stays private
+
🎯 Reranking Reciprocal Rank Fusion merges results for best-match precision

4 tools. Complete access.

search_keyword

Fast regex search powered by ripgrep. Configurable detail levels — return only what the model needs, nothing extra.

get_file

Read any file with line-range slicing. Fetch exactly the 20 lines you need instead of dumping a 1,000-line file.

symbols

AST-based symbol lookup via ast-grep. Find any function, class, or type definition in milliseconds with mode=find or mode=list.

hybrid_search_v2

Combined keyword + semantic search with reranking. Ask natural language questions about your codebase — no full file reads required.

Up in 3 steps

  1. 01

    Install

    shell
    curl -fsSL https://raw.githubusercontent.com/brian-lai/codetect/main/scripts/install-binary.sh | sh
# or: brew install brian-lai/tap/codetect
  2. 02

    Index your project

    shell
    cd /path/to/your/project
codetect init      # writes .mcp.json
codetect index     # indexes symbols + embeddings
  3. 03

    Start your LLM tool

    shell
    # codetect tools are auto-registered via MCP
claude        # Claude Code
# or open Cursor, Windsurf, Zed — it just works
