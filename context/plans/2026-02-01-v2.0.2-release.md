## Notes

### Why v2.0.2 (not v2.1.0)?

Per [semantic versioning](https://semver.org/):
- **MAJOR** (2.x.x): Breaking changes
- **MINOR** (x.1.x): New features (backward compatible)
- **PATCH** (x.x.2): Bug fixes only

This release only fixes a bug (registry not updating), so it's a patch release.

### CHANGELOG Format

Following [Keep a Changelog](https://keepachangelog.com/) format:
- **Added** - New features
- **Changed** - Changes in existing functionality
- **Deprecated** - Soon-to-be removed features
- **Removed** - Removed features
- **Fixed** - Bug fixes ← This release
- **Security** - Vulnerability fixes

### Auto-Update Mechanism

Users running `codetect update` will:
1. Query GitHub API for latest release tag
2. Download binary from GitHub releases
3. Replace existing binary
4. Verify new version: `codetect --version`

This relies on the GitHub release being published correctly.
